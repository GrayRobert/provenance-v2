# Guitar chord data attribution

The per-key JSON files in this directory are generated from
[szaza/guitar-chords-db-json](https://github.com/szaza/guitar-chords-db-json)
(MIT License, Copyright (c) 2019 Zoltan Szabo), with additional voicings from this
project (power chords and barre-from-open transpositions, see
`scripts/add-power-chords.js` and `scripts/add-barre-from-open.js`).
